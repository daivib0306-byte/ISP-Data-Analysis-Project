ISP Network Performance & Troubleshooting Automation

This project implements a complete Data Engineering and Analysis pipeline (ETL) designed for a telecommunications environment. It simulates, cleans, and analyzes 5,000 technical support tickets to identify network performance bottlenecks.
Features

    Data Generation: A custom script that creates a synthetic dataset with realistic ISP scenarios, including technical anomalies like negative latency and inconsistent date formats.

    Automated Cleaning: An ETL process using Pandas and NumPy to standardize customer data, handle missing values, and correct physically impossible network metrics.

    Technical Insights: Automated statistical analysis that calculates resolution rates and identifies high-latency categories.

Tech Stack

    Language: Python 3.x

    Libraries: Pandas, NumPy, Matplotlib

    Version Control: Git & GitHub

How to Run

    Clone the repository.

    Install dependencies: pip install pandas matplotlib numpy.

    Run the pipeline in order:
    
        python data_generator.py
        python data_cleaner.py
        python data_analysis.py
