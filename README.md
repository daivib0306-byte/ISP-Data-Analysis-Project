# ISP Technical Support Data Analysis & Automation

## Project Overview
This project demonstrates the automation of data cleaning and analysis for Technical Support operations within an Internet Service Provider (ISP). Leveraging my **2 years of experience** in Tier 1 and Tier 2 technical support, I developed this tool to transform raw, inconsistent ticket logs into clean, actionable datasets.

The goal is to eliminate manual errors and provide clear insights into network stability and customer satisfaction metrics.

## Key Features
* **Data Cleaning & Standardization**: Using Python (Pandas) to fix inconsistent date formats and standardize customer information.
* **Technical Validation**: Logic-based filtering to correct common ISP data errors, such as negative latency values or invalid status codes.
* **Incident Categorization**: Automatically mapping technical descriptions into clean categories (e.g., Layer 1/Physical issues vs. Layer 2/Configuration issues).
* **Operational Efficiency**: Reducing the data preparation time from hours of manual Excel work to seconds of automated processing.

## Tech Stack
* **Language**: Python 3.10+
* **Libraries**: Pandas, NumPy
* **Version Control**: Git & GitHub

## How to Run
1. Clone the repository to your local machine.
2. Ensure you have the required libraries: `pip install pandas numpy`
3. Place your raw data in the project folder and run: `python cleaning_script.py`
